import simpy
import random

def pasajero(env, id_p, ventanillas, tiempos_espera):
    llegada = env.now
    with ventanillas.request() as req:
        yield req
        espera = env.now - llegada
        tiempos_espera.append(espera)
        # Servicio exponencial con media 1/15 h = 4 min
        yield env.timeout(random.expovariate(15.0))

def generador_flujo(env, ventanillas, tiempos_espera):
    id_p = 1
    while True:
        # Llegadas Poisson con tasa lambda = 180 pas/h
        yield env.timeout(random.expovariate(180.0))
        env.process(pasajero(env, id_p, ventanillas, tiempos_espera))
        id_p += 1

# Entorno y recurso SimPy con x ventanillas abiertas
env = simpy.Environment()
x_ventanillas = 15  # Solución óptima
ventanillas = simpy.Resource(env, capacity=x_ventanillas)
tiempos_espera = []

env.process(generador_flujo(env, ventanillas, tiempos_espera))
env.run(until=4.0)  # Simular 4 horas pico

print(f"Espera promedio simulada: {sum(tiempos_espera)/len(tiempos_espera)*60:.2f} min")
1. Carga y Ergodicidad

a = λ / μ = 180 / 15 = 12

ρ = a / c = 12 / c

Para estabilidad, ρ < 1 ⇒ c ≥ 13 ventanillas mínimas.

2. Erlang C y Little

P_w = C(c, a)

L_q = P_w · ρ / (1 - ρ)

W_q = L_q / λ

Restricción SLA: W_q ≤ 0.1 h (6.0 min).

3. Función de Costo (y)

CT(x) = C_s · x + C_w · L_q(x)

y = 50 · x + 40 · L_q(x)

Mínimo global convexo evaluado en x* = 15.

Ejercicio 4: Optimización de Colas en Servicio de Migración Aeroportuaria

Técnica de I.O. y Tecnología: Teoría de Colas y Simulación de Eventos Discretos

Contexto Operativo: En la zona de migración de un aeropuerto internacional se registra una tasa de llegada de pasajeros $\lambda = 180 \text{ pasajeros/hora}$ durante horas pico. Cada ventanilla abierta procesa en promedio $\mu = 15 \text{ pasajeros/hora}$. Se debe determinar el número óptimo de ventanillas para cumplir los estándares de servicio al menor costo.

• Estructura de Costos: Costo de operación por ventanilla abierta = $50 USD/hora. Costo de penalización por espera de pasajeros = $40 USD/hora por pasajero en cola.

• Restricción de Nivel de Servicio: El tiempo promedio de espera en cola de un pasajero no debe superar los 6 minutos (0.1 horas).

• Escenario Actual (Sin Optimizar): Apertura fija tradicional de 16 ventanillas fijas durante todo el turno. Costo total del sistema reportado: $1,120 USD/hora.

Preguntas Analíticas a Resolver:

1. ¿Cuál es el número entero óptimo de ventanillas que minimiza el costo total combinado cumpliendo la restricción de 6 minutos de espera? (Resuelto: x* = 15 ventanillas, y* = $801.07 USD/h)

2. ¿Qué impacto cuantitativo en tiempo de espera y costo por hora genera la solución optimizada frente a las 16 ventanillas fijas? (Resuelto: Ahorro de $318.93 USD/h = $1.86M USD/año con solo +13.5s de espera)
