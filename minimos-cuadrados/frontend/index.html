Métodos Numéricos

Cuando el sistema no es cuadrado, la mejor respuesta es la que menos se equivoca

Con más ecuaciones que incógnitas casi nunca hay una solución exacta; con menos, hay infinitas. El método de mínimos cuadrados elige la solución que minimiza \(\lVert A\mathbf{x}-\mathbf{b}\rVert_2\) y, entre empates, la de norma mínima.

Recorrer la teoría Resolver un sistema
$$\hat{\mathbf{x}} = \arg\min_{\mathbf{x}\in\mathbb{R}^n} \lVert A\mathbf{x}-\mathbf{b}\rVert_2^2$$ $$A^{T}A\,\hat{\mathbf{x}} = A^{T}\mathbf{b}$$

Fundamentos teóricos

Sistema \(A\mathbf{x}=\mathbf{b}\) con \(A\in\mathbb{R}^{m\times n}\), \(m\neq n\)

m > n

Sobredeterminado

Más ecuaciones que incógnitas (p. ej. muchas mediciones y pocos parámetros). En general es inconsistente: \(\mathbf{b}\) no está en el espacio columna de \(A\).

$$\hat{\mathbf{x}} = (A^TA)^{-1}A^T\mathbf{b}$$

Válido si \(\operatorname{rango}(A)=n\): \(A^TA\) es simétrica y definida positiva.

m < n

Subdeterminado

Menos ecuaciones que incógnitas. Si es consistente tiene infinitas soluciones \(\mathbf{x}_p + \mathcal{N}(A)\); se elige la de menor norma \(\lVert\mathbf{x}\rVert_2\).

$$\mathbf{x}^{*} = A^T(AA^T)^{-1}\mathbf{b}$$

Válido si \(\operatorname{rango}(A)=m\): \(AA^T\) es \(m\times m\) e invertible.

rango < mín(m, n)

Rango deficiente

Columnas o filas dependientes: \(A^TA\) y \(AA^T\) son singulares. Se usa la pseudoinversa de Moore-Penrose obtenida con la SVD.

$$\hat{\mathbf{x}} = A^{+}\mathbf{b} = V\Sigma^{+}U^{T}\mathbf{b}$$

Da la solución de mínimos cuadrados de norma mínima en todos los casos.

¿De dónde salen las ecuaciones normales?

Se minimiza la suma de los cuadrados de los residuos \(r_i = b_i - (A\mathbf{x})_i\):

$$S(\mathbf{x}) = \sum_{i=1}^{m} r_i^2 = (\mathbf{b}-A\mathbf{x})^T(\mathbf{b}-A\mathbf{x})$$

Igualando el gradiente a cero:

$$\nabla S = -2A^T(\mathbf{b}-A\mathbf{x}) = \mathbf{0} \;\Longrightarrow\; A^TA\,\hat{\mathbf{x}} = A^T\mathbf{b}$$

Interpretación geométrica

\(A\hat{\mathbf{x}}\) es la proyección ortogonal de \(\mathbf{b}\) sobre el espacio columna de \(A\). El residuo es perpendicular a cada columna:

$$A^T\mathbf{r} = A^T(\mathbf{b}-A\hat{\mathbf{x}}) = \mathbf{0}$$

Lo puedes ver y girar en la sección Geometría 3D.

Precaución numérica: ecuaciones normales frente a QR

Formar \(A^TA\) eleva al cuadrado el número de condición, \(\kappa(A^TA)=\kappa(A)^2\). Si \(\kappa(A)\approx10^{8}\), las ecuaciones normales pierden casi toda la precisión en doble precisión. Con \(A=QR\) se resuelve \(R\hat{\mathbf{x}}=Q^T\mathbf{b}\) sin ese problema. La calculadora muestra ambos resultados y ambos números de condición.

Caso de estudio: calibración de un sensor

Cuatro lecturas \((x_i, y_i)\) y un modelo lineal \(y = c_0 + c_1x\): 4 ecuaciones, 2 incógnitas

1 · Plantear el sistema sobredeterminado

Lecturas: \((1,2),\ (2,3),\ (3,5),\ (4,6)\). Cada punto aporta una ecuación \(c_0 + c_1x_i = y_i\):

$$\underbrace{\begin{bmatrix}1&1\\1&2\\1&3\\1&4\end{bmatrix}}_{A} \begin{bmatrix}c_0\\c_1\end{bmatrix} = \underbrace{\begin{bmatrix}2\\3\\5\\6\end{bmatrix}}_{\mathbf{b}}$$

\(\operatorname{rango}(A)=2\) pero \(\operatorname{rango}([A\mid\mathbf{b}])=3\): no hay solución exacta.

2 · Formar las ecuaciones normales

$$A^TA = \begin{bmatrix}4&10\\10&30\end{bmatrix},\qquad A^T\mathbf{b} = \begin{bmatrix}16\\47\end{bmatrix}$$ $$\begin{cases}4c_0 + 10c_1 = 16\\10c_0 + 30c_1 = 47\end{cases}$$

3 · Resolver por eliminación de Gauss

$$\left[\begin{array}{cc|c}10&30&47\\4&10&16\end{array}\right] \xrightarrow{F_2 - 0.4F_1} \left[\begin{array}{cc|c}10&30&47\\0&-2&-2.8\end{array}\right]$$ $$c_1 = \frac{-2.8}{-2} = 1.4,\qquad c_0 = \frac{47 - 30(1.4)}{10} = 0.5$$

Se intercambiaron las filas para pivotear con el mayor valor absoluto (10).

4 · Interpretar el resultado

$$\boxed{\,y = 0.5 + 1.4\,x\,}$$ $$\mathbf{r} = \mathbf{b} - A\hat{\mathbf{x}} = \begin{bmatrix}0.1\\-0.3\\0.3\\-0.1\end{bmatrix},\quad \sum r_i^2 = 0.2,\quad R^2 = 0.98$$ $$A^T\mathbf{r} = \begin{bmatrix}0\\0\end{bmatrix}\ \checkmark$$
